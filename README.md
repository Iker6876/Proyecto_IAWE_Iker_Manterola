# Proyecto_IAWE_Iker_Manterola

Visualizador del ledger de Bitcoin.

---

## 1. Descripción

Desarrollar una aplicación que permita consultar y visualizar de forma sencilla la información contenida en el ledger de Bitcoin.

---

## 2. Objetivo

-Facilitar la consulta de bloques.

-Mostrar información de las transacciones.

-Permitir consultar entradas y salidas de transacciones.

-Facilitar la comprensión del funcionamiento interno de una blockchain.

-Proporcionar una interfaz web sencilla para acceder a esta información.

---

## 3. Público objetivo

-Personas interesadas en Bitcoin y blockchain.

-Usuarios que quieran consultar información de transacciones.

## 5. Páginas o secciones

Hash del bloque.

Fecha.

Número de transacciones.

Hash del bloque anterior.

### Transacciones

TXID.

Inputs.

Outputs.

Cantidad de BTC.
